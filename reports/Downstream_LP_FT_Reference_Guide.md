# Downstream LP-FT (Linear Probing to Fine-Tuning) Reference Guide
**A Comprehensive Reusable Architectural, Algorithmic, and Practical Guide for Two-Stage Vision Transformer Fine-Tuning**

---

## Executive Summary
This document provides an exhaustive technical reference for the downstream classification and adaptation framework implemented in the `ag_foundation` codebase (`src/ag_foundation/training/cls_runner.py`). To transfer self-supervised DINO representations to downstream agricultural and remote-sensing tasks without representation collapse or catastrophic forgetting, we implement **LP-FT (Linear Probing followed by End-to-End Fine-Tuning)** equipped with **Layer-Wise Learning Rate Decay (LLRD)**, decoupled AdamW weight decay, and label smoothing.

---

## 1. Why LP-FT? The Optimization & Forgetting Problem

When fine-tuning a pre-trained Vision Transformer (`ViT-Base/16`) on a downstream supervised dataset:
1. **The Head Initialization Shock**: The classification head ($\mathbf{W}_{\text{head}} \in \mathbb{R}^{C \times D}$) is randomly initialized, while the transformer backbone ($\theta_{\text{backbone}}$) contains carefully structured self-supervised DINO features.
2. **Catastrophic Distortion**: If end-to-end backpropagation is enabled immediately at epoch 1, the massive initial error gradients generated by the random classification head propagate backward through all 12 transformer blocks, distorting and destroying the pre-trained spatial attention maps.
3. **The LP-FT Solution**:
   - **Stage 1 — Linear Probing (LP)**: The ViT backbone is completely frozen (`requires_grad = False`). The classification head alone is trained for $E_{\text{LP}}$ epochs until it aligns with the pre-trained feature manifold.
   - **Stage 2 — End-to-End Fine-Tuning (FT)**: The backbone is unfrozen (`requires_grad = True`), and all parameters are fine-tuned together using **Layer-Wise Learning Rate Decay (LLRD)** to protect early visual features.

```
                  STAGE 1: LINEAR PROBING (LP)                   STAGE 2: END-TO-END FINE-TUNING (FT)
                     (Epochs 1 to E_LP)                            (Epochs E_LP+1 to Total Epochs)
      
                     Input Image x                                           Input Image x
                           │                                                       │
                           ▼                                                       ▼
      ┌─────────────────────────────────────────┐             ┌─────────────────────────────────────────┐
      │         ViT-Base/16 Backbone            │             │         ViT-Base/16 Backbone            │
      │   (12 Transformer Blocks, FROZEN ❄️)     │             │    (UNFROZEN ── Layer-Wise LR Decay)    │
      │         requires_grad = False           │             │         requires_grad = True            │
      └────────────────────┬────────────────────┘             └────────────────────┬────────────────────┘
                           │                                                       │
                           ▼ [CLS] Feature z (768-d)                               ▼ [CLS] Feature z (768-d)
      ┌─────────────────────────────────────────┐             ┌─────────────────────────────────────────┐
      │     Classification Head (3-Layer MLP)    │             │     Classification Head (3-Layer MLP)    │
      │         requires_grad = True  🔥         │             │         requires_grad = True  🔥         │
      │         LR = Base LR (100%)             │             │         LR = Base LR (100%)             │
      └────────────────────┬────────────────────┘             └────────────────────┬────────────────────┘
                           │                                                       │
                           ▼                                                       ▼
                     Cross-Entropy Loss                                      Cross-Entropy Loss
```

## 2. Implementation Anatomy (`src/ag_foundation/training/cls_runner.py`)

### 2.1 LP-FT Two-Stage Execution Loop
In `cls_runner.py` (lines 275–286), the two-stage transition is governed automatically by `freeze_backbone_epochs`:

```python
# Default: 5 epochs of Linear Probing when loading DINOv3 / Agri-DINO weights
freeze_backbone_epochs = int(
    model_cfg.get("freeze_backbone_epochs", 5 if model_cfg.get("pretrained_source") == "dinov3" else 0)
)

for epoch in range(epochs):
    # LP-FT Two-Stage Fine-Tuning Control
    if freeze_backbone_epochs > 0:
        if epoch < freeze_backbone_epochs:
            model.backbone.requires_grad_(False)
            if epoch == 0:
                print(f"[LP-FT] Stage 1: Backbone frozen for epochs 1-{freeze_backbone_epochs} (Linear Probing head only)")
        elif epoch == freeze_backbone_epochs:
            model.backbone.requires_grad_(True)
            print(f"[LP-FT] Stage 2: Backbone unfrozen at epoch {epoch + 1} (End-to-end LLRD Fine-Tuning)")
```

### 2.2 Mathematical Formulation of Layer-Wise Learning Rate Decay (LLRD)
In `cls_runner.py` (`get_layerwise_lr_groups`, lines 183–214), each parameter group is assigned a geometric learning rate decay factor $\alpha \in (0, 1]$ based on its layer depth $\ell$:

$$\eta_{\ell} = \eta_{\text{base}} \cdot \alpha^{(L + 1 - \ell)}$$

Where:
- $L = 12$ is the total number of transformer blocks in `ViT-Base/16`.
- $\alpha = 0.75$ (`model.layer_decay`) is the inter-layer decay ratio.

**Effective Learning Rate Hierarchy for $\eta_{\text{base}} = 1\times 10^{-3}, \; \alpha = 0.75$**:
| Layer Identifier ($\ell$) | Parameter Group Name | Exponent ($13 - \ell$) | Effective Learning Rate ($\eta_\ell$) | % of Base LR |
| :--- | :--- | :--- | :--- | :--- |
| **Classification Head** ($\ell = 13$) | `head.*`, `fc.*` | $0$ | $1.00 \times 10^{-3}$ | **100.0%** |
| **Transformer Block 11** ($\ell = 12$) | `blocks.11.*` | $1$ | $7.50 \times 10^{-4}$ | **75.0%** |
| **Transformer Block 10** ($\ell = 11$) | `blocks.10.*` | $2$ | $5.63 \times 10^{-4}$ | **56.3%** |
| **Transformer Block 9** ($\ell = 10$) | `blocks.9.*` | $3$ | $4.22 \times 10^{-4}$ | **42.2%** |
| **Transformer Block 6** ($\ell = 7$) | `blocks.6.*` | $6$ | $1.78 \times 10^{-4}$ | **17.8%** |
| **Transformer Block 3** ($\ell = 4$) | `blocks.3.*` | $9$ | $7.51 \times 10^{-5}$ | **7.5%** |
| **Transformer Block 0** ($\ell = 1$) | `blocks.0.*` | $12$ | $3.17 \times 10^{-5}$ | **3.2%** |
| **Patch & Pos Embeds** ($\ell = 0$) | `patch_embed.*`, `pos_embed` | $13$ | $2.38 \times 10^{-5}$ | **2.4%** |

**Why LLRD Works**:
- Shallow layers ($\ell \le 3$) capture low-level, domain-invariant visual features (edges, color gradients, textures); LLRD restricts their learning rate to $\approx 2\text{--}7\%$ of the base rate, preventing overfitting and catastrophic forgetting.
- Deep layers ($\ell \ge 9$) learn high-level semantic representations; LLRD grants them higher rates ($\approx 40\text{--}75\%$) to adapt to domain-specific agricultural classes.

## 3. Decoupled Weight Decay & Regularization Stack

### 3.1 Parameter Decoupling Rule
In `get_layerwise_lr_groups`, weight decay is selectively applied only to multi-dimensional weight matrices:
```python
if param.ndim <= 1 or name.endswith(".bias") or "cls_token" in name or "pos_embed" in name:
    wd = 0.0
else:
    wd = weight_decay  # Default: 0.05
```
- **Exempt from Weight Decay (`wd = 0.0`)**: All 1D bias vectors, LayerNorm affine gains/biases, `cls_token`, and positional embeddings (`pos_embed`).
- **Subject to Weight Decay (`wd = 0.05`)**: All 2D linear projection matrices (`qkv.weight`, `proj.weight`, `mlp.fc.weight`).

### 3.2 Full Structural Regularization Stack
To prevent overfitting on downstream datasets, `RemoteSensingClassifier` combines four independent regularization mechanisms:
1. **Stochastic Depth (`drop_path_rate = 0.2`)**: Randomly drops residual block connections during training, scaling linearly from $0.00$ at Block 0 to $0.20$ at Block 11.
2. **Attention Dropout (`attn_drop_rate = 0.1`)**: Drops attention softmax weights to prevent co-adaptation on specific token heads.
3. **Linear Dropout (`drop_rate = 0.1`)**: Drops neuron activations after transformer MLP blocks.
4. **Head Dropout (`head_dropout = 0.2`)**: Dropout layer inserted immediately before the final classification linear projection head.
5. **Label Smoothing (`label_smoothing = 0.1`)**: Uses smoothed cross-entropy targets:
   $$\mathcal{L}_{\text{CE}} = -(1 - \alpha) \log p_{y} - \frac{\alpha}{C} \sum_{c=1}^C \log p_{c}, \quad \alpha = 0.1$$
   This prevents overconfident logit predictions on agricultural images with ambiguous class boundaries.

## 5. Execution & CLI Anatomy

### 5.1 PowerShell Launch Command
```powershell
conda activate ag-foundation; $env:PYTHONPATH = "src"; python -m ag_foundation finetune-cls --config configs/finetune_classification_full_scale.yaml
```

### 5.2 Anatomy of the Execution Process
1. **Module Dispatcher (`python -m ag_foundation finetune-cls`)**:
   - Parses command verb `finetune-cls` in `src/ag_foundation/cli.py` and calls `src/ag_foundation/training/cls_runner.main()`.
2. **Backbone Loading**:
   - Loads your pre-trained DINO checkpoint (`best.pt` / `last.pt`), extracts keys with prefix `student_backbone.` (or raw `timm` keys), and injects them into the `ViT-Base/16` backbone.
3. **Stage 1 (Linear Probing, Epochs 1–5)**:
   - Prints: `[LP-FT] Stage 1: Backbone frozen for epochs 1-5 (Linear Probing head only)`
   - Computes gradients exclusively for the linear classifier head.
4. **Stage 2 (LLRD Fine-Tuning, Epoch 6–50)**:
   - Prints: `[LP-FT] Stage 2: Backbone unfrozen at epoch 6 (End-to-end LLRD Fine-Tuning)`
   - Unfreezes all 12 blocks, constructs 14 layer-wise learning rate groups (`get_layerwise_lr_groups`), and applies AdamW updates with cosine learning rate decay.
5. **Checkpointing & Early Stopping**:
   - Evaluates Top-1 and Top-5 accuracy on the validation split after every epoch.
   - Automatically saves `best.pt` when validation Top-1 accuracy exceeds previous bests.
   - Triggers early stopping if validation Top-1 accuracy stagnates for `early_stopping_patience = 10` consecutive epochs.

## 6. How to Reuse This Pipeline for Any New Dataset

### Checklist for Porting to a New Project:
1. **Organize Your Downstream Dataset**:
   - Format your target dataset as a PyTorch `ImageFolder` structure:
     ```
     /path/to/my_dataset/
       ├── train/
       │     ├── class_a/ (e.g., healthy_leaf/)
       │     └── class_b/ (e.g., rust_disease/)
       └── val/
             ├── class_a/
             └── class_b/
     ```
2. **Set `freeze_backbone_epochs` Appropriately**:
   - **For Small Target Datasets (< 5,000 images)**: Set `freeze_backbone_epochs: 10` and use a stronger layer decay (`layer_decay: 0.65`) to avoid overfitting.
   - **For Large Target Datasets (> 50,000 images)**: Set `freeze_backbone_epochs: 3` and use a gentler layer decay (`layer_decay: 0.80`).
3. **Verify LLRD Distribution in Logs**:
   - At startup, confirm the log output prints:
     `LLRD effective LRs: min=2.38e-05  max=1.00e-03  (14 groups)`
   - This confirms that layer-wise learning rate decay is active and properly scaling from patch embed to classification head.
